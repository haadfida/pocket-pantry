# Screenshots to capture

Take these on a simulator (iPhone 15 Pro or Pixel 8, portrait) with some sample data
loaded, then save them in this folder with the exact filenames below.

1. `hero.png` - Recipes tab with several recipes in the list (light theme). Used as the hero image in the root README.
2. `cook-now.png` - Cook tab showing recipes that can be made from current pantry stock.
3. `grocery.png` - Groceries tab with a mix of "To buy" and "In cart" items.
4. `stats-dark.png` - Stats tab (bar and pie charts) with Dark mode enabled in Settings.

Tips: use the simulator's built-in screenshot (Cmd+S on iOS Simulator), keep the status bar clean,
and keep each file under 500 KB.
